How it fits Orbyte

Orbyte has no native sales or stock module. Restock Autopilot pulls POS data in through Orbyte Connect and turns it into approvals inside Orbyte's existing request-and-approve flow, with the same audit trail. Because it only needs one generic data shape, the same module works for a minimart, a cafe, a hardware shop or an online seller.

flowchart LR
  POS[POS or spreadsheet export] -->|Orbyte Connect| API[Restock API on Replit]
  API --> F[Forecast model]
  API --> R[Reorder rules]
  API -->|numbers only| LLM[LLM on RunPod GPU]
  LLM -->|plain-language reason| API
  API --> A[Approval in Orbyte]
  A --> PO[Purchase order + supplier message]
  A --> LOG[(Activity log)]
